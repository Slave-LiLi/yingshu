# 映枢 0.3.13 / v6 手机实测

已安装到通过USB连接的荣耀10（COL-AL10、Android10、麒麟970），安装包SHA256已与手机中的base.apk逐字节核对。本次APK保留0.3.12界面和38条按键规则，更新模型及版本号。

## 准确率

- **手机文件推理：197张输入的张量与电脑逐字节一致。** 新增验证27/27，新增留出63/63（60张枪械＋3张无HUD）；旧验证36/36，v4旧回归18/19，v5旧回归49/52。旧样本共4张低置信度拒绝，没有通过阈值的错认或倍镜错位。
- 初次测试脚本将Android未识别枪械的空字符串与Python的unknown按字面比较，误记了4张负样本。按应用实际语义统一为未知后重新跑完197张，模型和APK没有因此改动。
- **已安装APK经NDI逐项显示测试：68/68正确。** 其中63项为新视频完整留出集，另外5项覆盖VK、复仇女神、L-STAR、猎兽、CAR；复仇女神这一项属于旧训练拟合检查，不是独立测试。
- 每个输入帧带校验码，读取手机实际预览确认输入已切换后，等待700ms，取随后2秒观察中的第一条识别结果评分。没有从多次结果中挑选正确答案。
- NDI测试使用1080p画面，固定样本放回原始右下角坐标，其他区域为背景；枪名行由既有遮罩清零，模型只使用枪械与倍镜图标，不使用OCR。
- 以上样本来自已确认的录屏和旧素材，**不是独立新对局准确率，也不代表快速切枪的每一帧均正确。** 动态视频部分用于测速，没有报告未经逐帧标注的准确率。

## 实际视频识别速率

原始111秒、1920×1080、30fps录屏通过NDI传入已安装APK，节能关闭、自动发键关闭。先进行80秒带界面观察的记录，再对开关预览各进行60秒不调用界面采样和截图的记录。下表是后两次测试中每5秒统计窗口平均值的中位数。

| 项目 | 开启预览 | 关闭预览 |
|---|---:|---:|
| 识别结果/秒 | 3.15 | 3.16 |
| 预处理 | 48.52 ms | 47.89 ms |
| 模型推理 | 237.37 ms | 235.18 ms |
| 手机收到帧到识别结果 | 303.29 ms | 292.59 ms |

开预览每个窗口为2.94–3.22次/秒，关预览为2.98–3.29次/秒。两次各得到11个统计窗口、188次识别。关闭预览对识别速率改善很小，当前主要耗时在手机CPU模型推理，其次是预处理。

这些时间不包含OBS采集、编码和网络传输，也不是电脑画面到手机显示的总延迟。手机USB供电；开预览这一轮电池温度约33–35℃。上一版历史实测约3.2次/秒，但素材和测试时间不同，不能当作本次严格A/B对照。
