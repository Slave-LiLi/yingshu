识别范围
单个联合模型同时输出 VK、R301、R99、复仇女神、转换者、L-STAR、猎兽、CAR 和倍镜；不使用枪名 OCR。
除 R99 外，每枪预留无镜、1 倍、2 倍、3 倍、4 倍规则；R99 仅无镜和 1 倍。
2–4 倍可调镜统一按 4 倍处理。
v5 训练批次新增素材仅覆盖：转换者无镜；L-STAR 无镜和 3 倍；猎兽 2 倍；CAR 2 倍。
新枪其他倍镜规则可以设置，但当前素材没有验证这些状态。复仇女神仍只有 2–4 倍镜素材。
先前新增录屏的 R99 已按用户确认标注为全程 1 倍镜；克雷贝尔相关片段完全排除，不作正例或负例训练。
v6 新增 R99 1倍、转换者 1倍、R301 2/3/4倍素材。训练信息见 training/provenance-v6.json，手机实测见 docs/VALIDATION.md；同源录像结果不代表独立泛化准确率。

界面与导航
左上角菜单打开左侧导航：识别、自定义按键、设备连接、视频源、设置与诊断。
点击半透明遮罩或返回可关闭菜单；其他页面返回先回识别页。当前页面在侧栏高亮。
侧栏展开/收起分别使用 280/230ms 滑动，遮罩同步淡入淡出；选中项用 180ms 过渡，页面切换用 220ms 淡入和轻微位移。
普通按钮与导航项有按下/松开反馈；四个功能开关采用胶囊滑块，按下拉伸、松开切换并恢复。
首页以视频和上方“枪械＋倍镜 → 按键”为中心；自定义按键独立页面展示完整 38 项。
M3/USB 操作在设备页，来源选择/NDI 主机/刷新在视频源页，预览、节能和诊断在设置页。
这些页面保留同一组控件与视频/推理实例，导航切换不会停止接收或重置识别。
外观默认跟随系统，也可在“设置与诊断 → 选择外观”单独选择浅色或深色；原生菜单、编辑对话框、下拉选项和系统栏使用对应主题。
设置页主题滑块既可点击，也可按住慢慢左右拖动；滑块、日月图案和整页配色随手指连续变化。松手后按中点吸附到浅色或深色，未越过中点可回到原状态。
拖动取消、主触点离开或转为竖向滚动时恢复原状态，第二根手指不会接管滑块；只有最终主题改变才提交一次。
主题过渡直接在现有界面中插值背景、文字、卡片、图标、按钮及系统栏颜色，拖动、松手吸附和整页变色使用连续进度。取消拖动时配色随滑块一起恢复；系统关闭动画时直接使用最终状态。
跟随系统模式仍受支持。系统自动改变明暗时的动画尚需单独真机验收，不能将应用内主动切换的验证等同于自动系统切换验证。
显式外观选择保存到独立 appearance 偏好，不修改按键规则；原生选择框和编辑对话框使用当前最终主题。
主题切换保留当前 Activity、页面和滚动位置，不再叠加旧界面截图或重建 Activity；切换主题及侧栏导航均不会停止接收或重启识别模型。真正离开前台时仍执行原有 onStop 策略：停止视频、断开 M3、关闭自动输出，返回后不自动启动。

自定义按键
从首页“自定义按键”按钮或左侧菜单进入 38 项规则页：37 个枪械＋倍镜组合，以及“未识别到枪械”。
首次进入前显示“HCL是不是专制主义？”。选择“是”后进入，并在本机记住通过状态；选择“不是”则退出当前应用任务，按原有 onStop 流程停止视频、断开 M3 并关闭自动发键。
选择“不是”不会记为通过，下次进入仍需回答；清除应用数据或卸载后重新安装也会重新提示。通过状态独立保存在本机，不随按键文本导出，也不上传回答。
原 18 项 ID 与存储键完整保留（含 unknown_gun）；新增 20 项默认未分配，升级保留原按键。
按键支持普通键、F1–F24 及 Ctrl/Shift/Alt/Win 组合。自动输出每次启动默认关闭；识别不要求连接 M3。
编辑任一规则，点击当前按键即可打开可搜索的按键列表；支持英文字母、数字、F1–F24 以及“回车”“空格”“删除”“方向键”“小键盘”等常见中文键名，英文不区分大小写。
空搜索显示全部按键，精确匹配优先；没有匹配时显示空结果。Ctrl、Shift、Alt、Win 仍在外层编辑框分别勾选。
点击搜索结果只选择本次编辑的候选按键；按外层“保存”才写入规则。取消按键选择或取消规则编辑不会保存修改；筛选不改变按键对应的 HID 值。
“未识别到枪械”仅用于有效视频帧正常完成推理后，枪型为空或不确定的结果。
已识别枪械但倍镜不确定、未知的命名枪型、R99 不支持的镜型，均不套用这项规则。
断流、停止视频、关闭识别、模型未就绪/错误、非有限数输出或收到的过期结果，不能生成该项按键。

按键文本导入导出
“导出文本”导出全部 38 项规则并复制到剪贴板，也可保存为 TXT 文件；文本不含设备序列号、激活信息、首次进入回答或其他手机偏好。
“导入文本”可粘贴导出的完整文本。导入会先校验格式、全部规则 ID、主按键和修饰键，确认完整且有效后一次替换 38 项配置；取消或校验失败不改变原规则。
导入文本必须包含全部 38 项，重复、未知或缺失规则，以及不支持的按键、非法修饰键均会拒绝；不把截断文本当成部分更新。
导入前的配置与新规则一起提交到规则偏好，供“恢复导入前配置”恢复最近一次导入前的完整配置。恢复只影响按键，不改变模型、主题、视频和连接设置，也不会主动发送按键。
文本首行为 YINGSHU_KEYS_V1，规则行使用“规则 ID=组合键”，以 # 开头的整行为注释。英文键名不区分大小写；建议在应用导出的文本上修改，保留全部规则 ID。
例如 VK47|none=Ctrl+F5、R301|two_x=F10、unknown_gun=未分配。主按键 =、# 和“小键盘 +”均作为按键字面值保留，不作为注释或额外字段处理。
文本兼容 UTF-8 BOM、CRLF 换行和空行，不支持行尾注释。实际导入行为和文件导出应以本版验收记录为准；上述说明不代替真机验证。

发送与显示
每次实际发送要求新的正常结果、帧龄不超过 500ms、自动输出已开启、M3 已就绪且规则已分配。
同一状态至少连续 3 次观察且持续 300ms 后提交一次；持续相同状态不逐帧重复发送。
结果到期时清除预览上方的旧枪械/映射显示；到期回调绝不发送按键。
短间隔正常观察的确认和去重历史保留；实际停止、关闭、错误或收到过期结果会重置确认。
界面“已提交”只表示已提交 BLE 队列，不证明电脑或游戏已收到按键。

输入、遮罩与模型
读取 1920×1080 源中的 (1472,936,320,128) 区域，先应用冻结遮罩，再上下各补 96 行 RGB114 成 320×320，不缩放图标。
遮罩 SHA256：0f035302b617d2cb0c62b728a4158d2eae9f1df6f5215dd51f7447238e9cfaac，保留 21024/40960 像素。
遮罩只影响推理副本，完整视频预览不加黑。HUD 布局、比例和镜外观变化仍需补充素材验证。
最终模型目录仅 joint.onnx、panel-mask.bin、manifest.json，schema_version 6。
13 类顺序：VK47、R301、R99、NEMESIS、ALTERNATOR、LSTAR、PROWLER、CAR、none、one_x、two_x、three_x、four_x。
输入 [1,3,320,320]；输出 [1,300,6]；枪类 0–7，镜类 8–12 映射为 0–4；未知镜不能误当无镜。
CPU intra-op 2 线程、单工作线程、一个会话、每帧一次 run；数值异常走错误处理。
构建和运行核对模型散列/大小、类顺序、形状和遮罩，防止混用旧 schema 模型。
本工程已包含冻结 v6 的 joint.onnx、panel-mask.bin 和 manifest.json，均沿用 schema6 契约。
模型 SHA256：0ed610790a14323061d8ba102c9c70aac32a03ecd28d872d187fd14587440528，大小 9701857 字节；本版更新模型，保留原遮罩、预处理与推理规则。

视频与硬件
沿用 NDI 持续接收、取最新帧、预览缩小和原尺寸识别区域；节能仅降低投递频率。
关闭预览仍可识别，关闭识别可保留视频。USB 采集沿用 1920×1080 MJPEG/BULK 路径。
本次未扩展 USB 等时/YUY2 或其他分辨率支持，未更改 OBS 设置。
离开前台停止视频并断开 M3。实际 USB/M3 发键验收与文件推理、NDI 观察分开报告。
局部 profile 不是电脑到手机的端到端延迟；10fps 是接受上限，不是速度承诺。
